## 🇫🇷 Description

### VPN Checker – Barre de menu macOS

VPN Checker est un utilitaire léger pour macOS qui surveille en temps réel l'état de votre connexion VPN et analyse la sécurité de votre réseau directement depuis la barre de menu (xbar / SwiftBar).

L'application fournit une vue d'ensemble claire de votre environnement réseau : adresse IP publique, géolocalisation, état du VPN, configuration DNS, détection des fuites, performances réseau et bien plus encore.

Conçu pour les utilisateurs soucieux de leur confidentialité, VPN Checker combine plusieurs techniques de détection afin de fournir un diagnostic fiable, même lorsque les services externes sont temporairement indisponibles.

### Fonctionnalités

* 🔐 Détection automatique de l'état du VPN
* 🌍 Affichage de l'adresse IP publique
* 🗺️ Géolocalisation (pays et fournisseur d'accès)
* 🏢 Identification du fournisseur réseau (ISP, Datacenter, VPN)
* 🛡️ Détection des fournisseurs VPN (ProtonVPN, Mullvad, NordVPN, etc.)
* 🌐 Identification du type de tunnel

  * WireGuard
  * OpenVPN
  * Tailscale
  * ZeroTier
* 🔒 Vérification du Kill Switch
* ⚠️ Détection du Split Tunneling
* 🌐 Détection des proxys système
* 🧅 Détection de Tor
* 🍎 Détection d'Apple Private Relay
* 🛡️ Analyse des serveurs DNS utilisés
* 🔍 Détection des fuites DNS (IPv4 et IPv6)
* 🔐 Vérification du chiffrement DNS (DoH/DoT)
* 🔄 Analyse de la cohérence réseau
* 📡 Mesure de la latence et du jitter
* 📊 Calcul d'un score global de sécurité
* 🆔 Génération d'une empreinte réseau (Network Fingerprint)
* 📝 Journalisation structurée (JSON)
* 🐞 Mode Debug pour le diagnostic
* ⚡ Exécution rapide optimisée pour SwiftBar/xbar
* ⚙️ Configuration personnalisable

### Compatibilité

* macOS
* Ruby
* SwiftBar
* xbar

# 🇬🇧 Description

### VPN Checker – macOS Menu Bar Monitor

VPN Checker is a lightweight macOS utility that continuously monitors your VPN connection and evaluates your network security directly from the menu bar using SwiftBar or xbar.

It provides a comprehensive overview of your network environment, including your public IP address, geolocation, VPN status, DNS configuration, leak detection, and network performance.

Designed for privacy-conscious users, VPN Checker combines multiple detection methods to deliver reliable diagnostics, even when external services are temporarily unavailable.

### Features

* 🔐 Automatic VPN status detection
* 🌍 Public IP address detection
* 🗺️ Geolocation (country and ISP)
* 🏢 Network provider identification (ISP, Datacenter, VPN)
* 🛡️ VPN provider detection (ProtonVPN, Mullvad, NordVPN, and others)
* 🌐 Tunnel protocol identification

  * WireGuard
  * OpenVPN
  * Tailscale
  * ZeroTier
* 🔒 Kill Switch verification
* ⚠️ Split Tunneling detection
* 🌐 System proxy detection
* 🧅 Tor network detection
* 🍎 Apple Private Relay detection
* 🛡️ DNS server analysis
* 🔍 IPv4 and IPv6 DNS leak detection
* 🔐 Encrypted DNS (DoH/DoT) detection
* 🔄 Network consistency analysis
* 📡 Latency and jitter measurements
* 📊 Global security score
* 🆔 Network fingerprint generation
* 📝 Structured JSON logging
* 🐞 Debug mode for troubleshooting
* ⚡ Optimized for fast SwiftBar/xbar execution
* ⚙️ Fully configurable settings

### Compatibility

* macOS
* Ruby
* SwiftBar
* xbar
